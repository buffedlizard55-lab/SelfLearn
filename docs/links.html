Re-running the check

  • python3 tools/verify_links.py - resolve every published URL from this machine and write reports/link_check.json.
  • python3 tools/verify_links.py --label <where it ran> - record the machine, because a result is only interpretable together with the egress that produced it.
  • python3 tools/link_check_changed.py - report whether any URL changed outcome, which is what decides whether a fresh report is worth committing.
  • The Tests workflow runs the check on every push from a runner with unrestricted egress and commits the register when an outcome moves.

How to check this site. Every factual statement is a quotation from a document listed on the topic page, with a link and a stored copy. Every figure in the generated prose is traceable to a claim or an engine computation. The full data behind every page is in docs/data/. Reproduction steps and limitations are on the method page, and every unresolved problem the engine found is on the review page.
